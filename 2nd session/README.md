# 2nd session: Starlink downlink 방식 비교

OFDM, AFDM, OTFS, DD-a-OFDM 비교를 위한 공통 시나리오를 관리한다.
현재 `scenario.json`에는 위성과 지상국의 기하 조건 및 1차 평가 지표 BER을 정의했다.
Ku 다운링크, 공통 반송파 주파수 11.7 GHz, 공통 명목 격자 대역폭 60 MHz를
사용한다. 첫 다중경로 비교용 경로 수·지연·상대 전력·도플러 및 경로 위상의
시행 간 변경 방식과 경로 전력 정규화, 첫 수신 잡음 모델 및 파일럿
공정성 원칙을 정했다. 첫 기준 실험에서는 **LOS 단일경로 + AWGN과 공통
도플러 완전 보정**을 가정한다. `E_b`는 데이터 심볼 에너지 기준이며, 심볼
영역의 잡음 분산 계산 규칙과 에너지 보존형 파형 변환 정규화를 정했다.
첫 기준 실험의 샘플링은 네 방식 모두 **60 MHz, 추가 오버샘플링 없음**으로
정했다. 첫 기준 실험의 유효 프레임은 **주파수 256칸 × 시간 64심볼**로 정했다.
각 `Eb/N0`에서 네 방식 모두 **10,485,760개의 데이터 비트**를 측정한다.
AFDM의 첫 유효 신호 구성은 **256점 IDAFT × 프레임당 64블록**으로 정했다.
OTFS는 **OFDM 기반 ISFFT/SFFT와 직사각형 송수신 펄스**를 사용한다.
유효 파형 변환은 구현했으며, 채널·등화·BER 처리는 후속 단계다.
DD-a-OFDM의 첫 수신 알고리즘은 **DD-ML 채널 추정 + TF 선형 MMSE 등화**로 정했다.
후속 3경로 비교의 등화기 종류는 네 방식 모두 **선형 MMSE**로 맞춘다.
OFDM·AFDM·OTFS의 구체적인 채널 추정법과 채널행렬 구성·처리 범위는 계속 논의한다.
후속 파일럿 기반 3경로 비교의 공통 예산은 **파일럿·보호칸 25%, 총 파일럿 에너지
4,096 E_s**로 정했다. 데이터 심볼의 평균 에너지 `E_s=1`은 유지한다.
후속 3경로 비교에서는 네 방식 모두 **256샘플 블록마다 CP 5샘플**을 붙인다.
OFDM과 DD-a-OFDM의 파일럿은 주파수 2칸마다 × 시간 2블록마다 같은 TF 위치에 둔다.
AFDM은 블록당 파일럿 1칸 + 보호칸 63칸, OTFS는 DD 파일럿 1칸과 보호·예약 영역을 둔다.
네 방식 모두 파일럿·보호·예약칸 25%, CP 제외 총 파일럿 에너지 `4,096 E_s`를 유지한다.
파일럿은 방식 안에서 균등한 에너지를 쓰며, 알려진 고정 QPSK 위상열을 사용한다.
OFDM/DD-a-OFDM은 같은 값을 쓰고 AFDM도 같은 기본 위상열을 재사용한다.
수신기 세부 설계와 실제 채널 추정 성능은 계속 논의·검증한다.

## 첫 기준 실험: 공통 도플러 완전 보정

첫 단계는 네 방식의 기본 송수신 처리와 전력·잡음 정규화가 맞는지 확인하는
기준 실험이다. 채널에는 해당 시점의 궤도에서 계산한 공통 LOS 도플러를
적용하고, 수신기는 채널 생성기와 정확히 같은 도플러 값을 오차 없이 안다고
가정한다. 수신 AWGN을 더한 후 파형별 복조 전에 아래와 같이 보정한다.

`r_corrected[n] = r[n] × exp(-j × 2π × f_D × n / F_s)`

여기서 `f_D`는 선택한 시점의 공통 도플러, `F_s`는 샘플링 주파수다. 보정 후
잔여 공통 도플러는 **0 Hz**다. 이는 실제 도플러 추정기를 구현하는 대신 두는
이상적인 주파수 보정 가정이며, 다른 채널 정보까지 완벽히 안다는 결정은 아니다.
이 단계에서는 도플러 획득용 프리앰블이나 추정 오차 모델을 추가하지 않는다.
채널 추정·등화의 세부 설계는 계속 논의할 항목이다. 후속 3경로용 파일럿은 아래에 별도로 정했다.

동일한 데이터 비트 에너지와 이상적인 송수신 처리를 맞추면, 네 방식이 공통
비부호화 16-QAM의 AWGN 기준 BER과 일치하는지 확인할 수 있다. 이 단계의
결과로 도플러 대응 성능의 우열을 판단하지 않는다. 원래의 최고점·이탈 시점
도플러는 기록에 유지하지만, 완전 보정 후에는 두 시점 모두 잔여값이 0 Hz이므로
다른 조건이 같다면 BER 통계도 같아야 한다.

이 기준 실험을 확인한 뒤 다중경로에서의 도플러 영향을 논의한다. 아래의
기존 3경로 지연·전력 프로파일은 유지한다. 후속 비교는 공통 LOS 도플러를
완전히 보정한 A(지연만)와 B(같은 지연 + 경로별 도플러 차이의 단계적 증가)로
정했다. 최대 잔여 도플러는 부반송파 간격의 0·1·5·10·20%로 정했으며,
각 최대 크기 `d`에서 LOS·반사 1·반사 2의 잔여 도플러를 `[0, +d, -d]`로 정했다.
이 범위에서의 파일럿 추정 성능은 검증할 항목이며, 수신기 탐색 범위는 계속 논의한다.
아직 BER 시뮬레이터나 도플러 보정 처리를 구현·실행한 것은 아니다.

실험은 다음 순서로 확장한다. 각 단계의 구체적인 수치와 수신 방식은 해당
단계를 설계할 때 논의한다.

1. LOS 단일경로 + AWGN과 공통 도플러 완전 보정으로 기본 송수신을 확인한다.
2. 파일럿과 CP 등 파형별 보호구간을 설계하고 반영한다.
3. 이미 정한 LOS + 반사 2경로의 다중경로 통제 프로파일을 반영한다.
4. 다중경로에서의 경로별 도플러 차이 또는 보정 오차 등을 근거에 따라 논의한다.

## 채널 구성 순서

첫 비교의 기본 채널은 위성에서 지상국까지의 LOS 단일경로(LOS 포함 총 1경로)로
정했다. 위성 궤도에서 계산한 LOS 도플러를 적용한 뒤 수신기에서 완전히
보정하고, 수신 `Eb/N0`를 바꾸며 BER을 본다. 이는 다중경로를 무시한 통제
실험이지 실제 지상국 주변에 반사가 없다는 주장은 아니다. 이후 LOS를 포함한
다중경로 채널을 별도 비교 조건으로
추가한다. 첫 다중경로 실험은 LOS 1개와 추가 경로 2개, 총 3경로로 정했다.
이는 계산 가능한 통제 모델의 선택이지 해당 지상국에서 실제 측정된 경로
수가 아니다. 첫 다중경로 비교에 사용할 프로파일은 다음과 같다. 지연은 위성에서
지상국까지의 전체 전파시간이 아니라 LOS에 대한 **초과 지연**이다.

| 경로 | LOS 대비 초과 지연 | 60 MHz 기준 샘플 수 | LOS 대비 상대 전력 | LOS 대비 추가 도플러 |
| --- | ---: | ---: | ---: | ---: |
| LOS | 0 ns | 0 | 0 dB | 0 Hz |
| 반사 1 | 약 33.3 ns | 2 | −10 dB | 0 Hz |
| 반사 2 | 약 83.3 ns | 5 | −15 dB | 0 Hz |

두 도플러 시점에서 지연과 상대 전력은 동일하게 유지하고, 각 시점의 궤도에서
계산한 LOS 도플러를 세 경로에 공통으로 적용한다. 수신국과 주변 반사체가
고정된 상황의 첫 근사이며, 반사체의 실제 위치를 모르므로 경로별 추가
도플러를 임의로 주지 않는다. 이는 도플러 **편이**는 포함하지만 경로 간
도플러 **확산**은 포함하지 않는 A의 생성 프로파일이다. 후속 B에서는 아래
도플러 비교 계획에 따라 반사경로의 추가 도플러만 `[+d,-d]`로 바꾼다.
최대 크기와 경로별 부호·상대 크기는 정했다. 위 지연·전력
값은 통제 실험용 선택이지 실제 Starlink–성균관대 링크의 측정치나 표준 NTN 경로
프로파일이 아니다.

이 다중경로 통제 프로파일에서는 각 경로의 크기를 위 상대 전력대로 한 프레임
내내 고정한다.
반사경로의 상대 위상은 독립 BER 시행마다 새로운 무작위 조합을 사용하되,
한 시행의 프레임 안에서는 고정한다. 같은 시행의 네 파형과 저·고도플러
시점에는 동일한 초기 상대 위상 조합을 적용해 도플러 조건만 통제해서
비교한다. 같은 시행의 A/B와 B의 도플러 단계들에도 같은 초기 위상을 쓴다.
A의 생성 프로파일에는 공통 도플러의 위상 회전만 있다. B에는 추가로
`exp(j*2*pi*delta_f_p*t)`의 경로별 결정적 위상 회전이 생기며, 시간은 CP를
포함해 연속으로 흐른다. B의 총 경로 위상까지 프레임 안에서 고정하는 것은 아니다.
별도의 무작위 위상 변화나 경로 크기 변화는 추가하지 않는다. LOS의 초기 위상은
기준값 0으로 두고, 두 반사경로의 위상은 각 시행마다 독립적으로 0~360°의
연속 균등분포에서 선택한다. 이는 측정된 위상 분포라는 뜻이 아니다.

경로 전력은 표의 상대값을 유지하면서 평균 총전력이 1이 되도록 정규화한다.
정규화 전 선형 경로 전력은 `1`, `0.1`, 약 `0.0316`이며, 세 경로의 복소 이득을
모두 `1 / √(1 + 0.1 + 0.0316...)`배 한다. 단일 LOS 조건의 총전력도 1이다.
이는 경로 프로파일에 한 번 적용하는 공통 배율이며, 시행이나 주파수 칸마다
순간 수신 전력을 다시 맞추지는 않는다. 따라서 위상에 따른 보강·상쇄와
경로 간 −10/−15 dB 관계는 남는다. 후속 3경로 비교의 보호구간은 아래 공통 CP
규칙을 사용하고, 나머지 수신기 처리는 계속 논의한다.

## 공통 수신 정보: 첫 3경로 비교

후속 **첫 3경로 파일럿 기반 비교에서는 네 방식 모두 경로 수 `P=3`을 안다**고
합의했다. 같은 사전정보를 사용할 수 있게 하되, 각 알고리즘이 반드시 경로별
파라미터 형태로 채널을 추정해야 한다는 뜻은 아니다.

수신기에 실제 지연 **0·2·5샘플**, 경로별 도플러, 복소 이득의 정답은 제공하지
않고, 파일럿으로 채널을 추정한다. 우선 경로 수 검출 오차를 제외한 파라미터
추정·BER을 비교하기 위한 통제 조건이며, 결과에 경로 수를 알고 있다는 가정을
명시한다. 공통 규칙은 `scenario.json`의 `receiver_information_policy`에 둔다.

이 결정은 첫 단일경로 기준 실험의 공통 도플러 완전 보정을 변경하지 않는다.
후속 A/B의 공통 LOS 도플러도 완전히 보정한다. 경로별 추가 도플러의 정답은
수신기에 주지 않으며, 수신 알고리즘 세부 사항은 계속 논의한다.
경로 수까지 직접 추정하고 그 누락·과대 검출이 BER에 미치는 영향을 보는 실험은
확장 목록에 기록했으며, 검출 방법·문턱값·평가 지표는 아직 정하지 않았다.

## 첫 기준 실험의 샘플링

네 방식 모두 복소 기저대역 신호를 `F_s = 60 MHz`로 계산한다. 추가
오버샘플링 배율은 1이며 별도의 재샘플링을 하지 않는다. 이미 정한 격자에서
`F_s = N × Δf = 256 × 234.375 kHz = 60 MHz`이고, 샘플 간격은 약
16.7 ns, 유효 심볼당 샘플 수는 256이다. 이는 [FFT 크기·부반송파 간격과
샘플링 주파수의 관계](https://www.mathworks.com/help/5g/ug/use-custom-ofdm-sample-rate-and-custom-fft-size.html)에
따른다. 첫 LOS + AWGN 기준 실험의 계산량을 줄이기 위한 디지털 모델의
선택이며, 실제 반송파를 직접 샘플링하는 ADC 사양이라는 뜻은 아니다.

같은 샘플링 주파수만으로 공정성이 보장되지는 않는다. 대역폭·프레임 시간·
데이터 비트 수·비트 에너지와 잡음·채널 및 수신 정보·추가 자원 비용도 함께
맞춘다. 실제 스펙트럼 점유 대역폭과 필터는 이번 결정으로 확정하지 않는다.
시간 방향 64심볼은 첫 기준 실험에 사용하고, 이후 프레임 길이의 영향을 검토한다.

60 MHz는 모든 후속 실험에 영구 고정하는 값이 아니다. 더 자세한 다중경로·
도플러·필터 모델이나 파형 측정을 도입할 때는 네 방식 모두 샘플링을 높여도
BER이 Monte Carlo 불확실성 범위 안에서 유지되는지 확인한다. PAPR이나
스펙트럼 등을 측정한다면 해당 지표의 수렴도 함께 확인한다. 샘플링 배율과
구체적인 판정 기준은 후속 실험을 설계할 때 정하며, 이 검증은 아직 실행하지 않았다.

샘플링을 높여 비교할 때는 물리적인 대역폭·부반송파 간격·프레임 시간·
정보 비트 수·경로 지연과 이득·도플러·에너지 및 자원 비용 기준을 유지한다.
예를 들어 초과 지연 약 33.3 ns와 83.3 ns는 그대로 두고, 이를 표현하는
샘플 수를 바꾼다. 기존 2·5샘플은 60 MHz에서의 값이다. 서로 다른 샘플링
주파수에서는 샘플 간격까지 반영한 물리적 에너지 또는 그와 동등한 정규화
기준으로 신호 배율과 잡음 분산을 다시 계산한다.

## 파형 변환의 에너지 정규화

OFDM, AFDM, OTFS, DD-a-OFDM 모두 유효 신호의 변환 전후 총 에너지를
보존하는 **유니터리 정규화**를 사용한다. 같은 정규화된 이산 샘플 기준에서
입력 격자를 `s_grid`, 출력 유효 신호를 `x_useful`이라 하면 다음을 만족한다.

`sum(|x_useful|²) = sum(|s_grid|²)`

길이가 `L`인 Fourier 변환과 역변환은 각각 `1/√L` 배율을 사용한다.
주파수 방향 256점 변환에서는 각각 `1/16`이다. 2차원 Fourier 변환은 각 축에
이 규칙을 적용한다. 이는 [유니터리 FFT 정규화](https://numpy.org/doc/stable/reference/routines.fft.html#normalization)에
해당하며, 무작위 프레임마다 측정한 전력을 다시 맞추는 방식이 아니다.

OFDM과 DD-a-OFDM의 공통 OFDM 변환뿐 아니라, OTFS 및 DD-a-OFDM의
DD 영역 Fourier 변환에도 같은 원칙을 적용한다. AFDM은 Fourier 부분을
유니터리로 정규화하고, 크기가 1인 chirp 위상 인자를 사용하는 DAFT/IDAFT
쌍으로 에너지를 보존한다. [AFDM의 유니터리 DAFT](https://arxiv.org/pdf/2204.12798)도
복조 변환 전후에 백색 복소 AWGN의 통계가 유지됨을 설명한다. AFDM의
`c1`, `c2` 값이나 각 방식의 채널 추정·등화기는 이 정규화 결정과 별도로 정한다.

이 원칙은 CP 등을 붙이기 전, 수신기에서는 해당 보호구간을 제거한 후의
유효 신호 변환에 적용한다. 파일럿을 격자에 넣으면 그 에너지도 변환 과정에서
보존한다. CP 등 추가 샘플이 만드는 에너지는 따로 계산하며, 전체 프레임을
다시 정규화해 이 비용을 감추지 않는다. 실제 채널이나 등화기가 에너지를
보존해야 한다는 가정은 아니다. OTFS의 유효 파형 변환은 `otfs.py`에 구현했으며,
네 파형의 전체 BER 송수신 구성은 아직 구현하지 않았다.

## 잡음 모델

첫 BER 비교에는 복소 AWGN(가산성 백색 가우스 잡음)을 사용한다. LOS와
반사경로의 신호를 합친 뒤 수신단에서 잡음을 한 번만 더하며, 경로마다
별도의 잡음을 넣지 않는다. 잡음은 평균 0이고 샘플 간 독립인 모델로 둔다.
이는 파형 비교를 위한 통제 가정이며 실제 Ku 다운링크의 간섭·위상잡음 등
모든 손상을 재현한다는 뜻은 아니다. 잡음 적용은 아직 구현하지 않았다.

첫 기준 실험의 `E_b`는 **파일럿과 CP 등 보호구간의 에너지를 제외한 데이터
심볼 기준**으로 정의한다. 비부호화 16-QAM은 한 심볼당 4비트이고 평균 심볼
에너지가 1이므로, 정규화된 데이터 비트 에너지는 `E_b = E_s / 4 = 1/4`이다.
이 에너지 계산 기준은 실제 신호에서 파일럿이나 보호구간을 생략한다는 결정과는
별개다. 기존 파일럿 자원·에너지 공정성 원칙은 유지하며, 전체 전송 에너지를
정보 비트 수로 나눈 기준은 파일럿·보호구간 설계 이후 별도로 평가할 수 있다.

`gamma_b = 10^(Eb/N0[dB] / 10)`일 때, 정규화된 **데이터 심볼 영역**에서의
복소 잡음 분산은 `sigma_s² = E_s / (4 × gamma_b) = 1 / (4 × gamma_b)`로
계산된다. 실수부와 허수부의 분산은 각각 `sigma_s² / 2`다. 예를 들어
`Eb/N0 = 10 dB`이면 심볼 기준 복소 잡음 분산은 0.025, 각 성분의 분산은
0.0125다. 이는 [Eb/N0와 Es/N0의 관계](https://www.mathworks.com/help/comm/ug/awgn-channel.html)와
[복소 AWGN의 성분별 분산](https://www.mathworks.com/help/comm/ref/awgnchannel.htm)에 따른 계산이다.

심볼 기준 잡음은 독립적인 표준 정규 난수 `u, v`를 사용해
`n_s = sqrt(sigma_s² / 2) × (u + jv)`로 표현한다. 이 식의 분산을 실제 수신
파형 샘플에 적용할 때는 확정한 유니터리 변환 규칙을 사용한다. 같은 이산
샘플 격자에서 정방 유니터리 송수신 변환을 사용하고, 추가 재샘플링이나
필터 이득이 없으면 유효 시간 샘플의 복소 AWGN 분산도
`sigma_time² = sigma_s² = 1 / (4 × gamma_b)`다. 수신 유니터리 변환이
백색 복소 잡음의 공분산을 보존하기 때문이다. 첫 샘플링 격자는 60 MHz로
확정했다. 필터는 별도 설계 항목이며, 후속 실험의 재샘플링이나 필터에서
다른 배율이 생기면 실제 샘플 분산의 관계를 다시 계산한다.
매 시행의 순간 수신 전력을 측정해 잡음 세기를 다시 맞추지는 않는다.

## 첫 기준 실험의 프레임 길이

첫 LOS + AWGN 기준 실험에는 주파수 방향 256칸과 **시간 방향 64심볼**을
사용한다. `Δf = 234.375 kHz`이므로 보호구간을 제외한 유효 심볼 길이는
`1/Δf ≈ 4.267 µs`, 64심볼 길이는 약 `0.273 ms`다. 60 MHz 샘플링에서
유효 프레임은 `256 × 64 = 16,384`샘플이며, 명목 도플러 칸 간격은 약
`3.66 kHz`다. 후속 3경로 비교에서는 슬롯마다 CP 5샘플을 붙여 실제 전송 시간이
**278.4 µs**, 명목 도플러 칸 간격이 **약 3.592 kHz**가 된다. 아래의 공통 파일럿
자원·에너지 예산은 유지하며, 실제 데이터·파일럿 마스크는 아래 파일럿 비교 절과
`pilot_layouts.py`에 정의했다. 알려진 복소 파일럿 값도 고정 시퀀스로 구현했다.

64는 계산 규모를 정해 첫 실험을 시작하기 위한 값이며, 궤도에서 결정되거나
적절성·최적성이 검증된 값은 아니다. [DD-a-OFDM 참고 논문 표 I](https://arxiv.org/pdf/2508.04253#page=10)도
시간 방향 64심볼을 사용하지만 부반송파 간격이 15 kHz여서 프레임 시간은 약
4.27 ms다. 따라서 논문의 64심볼은 이번 약 0.273 ms 프레임에 그대로 적합하다는
근거가 아니다. 실제 실행시간과 프레임 길이에 따른 결과는 아직 측정하지 않았다.

후속 검토에서는 다른 프레임 길이의 실행시간과 BER을 확인한다. 이상적인
LOS + AWGN 기준에서는 변조·에너지·잡음 조건을 같게 하고 충분한 비트와
오류를 누적해 BER 통계가 일치하는지 확인한다. 이후 다중경로·시간 변화 채널을
비교할 때는 프레임 길이에 따라 관측 시간과 도플러 격자, 추정기 동작도 달라질
수 있으므로 결과가 같아야 한다고 요구하지 않는다. 각 길이에서 네 방식의
전송 자원을 맞추고 차이를 해석한다. 추가 길이와 판정 기준은 추후 정하며,
이 검증은 아직 실행하지 않았다.

현재 이탈 시점의 공통 도플러 절댓값 약 261 kHz는 부반송파 간격
234.375 kHz보다 크다. 시간 심볼 수만 늘려서는 심볼 간 도플러 관측의
모호성을 해결할 수 없다. 첫 단일경로 기준 실험에서는 채널 생성기가 사용하는
공통 도플러를 수신기도 정확히 알고, 파형별 복조 전에 완전히 보정한다고
가정하므로 이 큰 주파수 이동의 획득 문제는 제외한다. 첫 기준 실험은 위의
64심볼을 사용한다. 아래의 CP 결정은 후속 3경로 비교에 적용하며, 실제 파일럿
배치와 도플러 추정·추적 방법은 별도로 설계한다. 후속 채널 비교에 사용할 프레임
길이는 검토 결과에 따라 재평가한다.

## 공통 보호구간: 후속 3경로 비교

네 방식 모두 **유효 신호 256샘플마다 CP 5샘플**을 붙이고, 수신기에서 제거한
후 유효 샘플을 복조한다. 기준은 기존 경로 0·2·5샘플의 **LOS 대비 최대 초과
지연 5샘플**이다. 위성에서 지상국까지의 전체 전파시간을 CP 길이로 쓰는 것은 아니다.

이는 정렬된 수신 구간과 현재의 정수 샘플 지연 모델에서의 최소 길이다.
시간 정렬 오차·분수 지연 필터의 꼬리·더 큰 지연 범위를 도입하면 다시 검토한다.
구체적인 시간 동기화 획득 알고리즘을 이번에 선택한 것은 아니다.

| 항목 | 후속 3경로 비교 설정 |
| --- | ---: |
| 유효 블록 | 256샘플 |
| 블록별 CP | 5샘플, 약 83.33 ns |
| 전송 슬롯 | 261샘플, 4.35 µs |
| 프레임 | 64슬롯, 16,704샘플 |
| CP 샘플 합계 | 320샘플 |
| 실제 프레임 시간 | 278.4 µs |
| 명목 도플러 격자 간격 | 약 3,591.954 Hz |

부반송파 간격은 유효 구간 기준 **234.375 kHz**를 유지한다. 도플러 위상과 채널
재구성에는 CP를 포함한 시간축을 사용한다. 슬롯 `n`의 유효 샘플 `q`는 첫 CP
샘플을 시간 원점으로 두면 `((256+5)*n+5+q)/F_s`에 해당한다.

AFDM은 현재 `N=256`이 짝수이고 `2*N*c1=5`가 정수이므로 CPP가 일반 CP와
같아진다. [AFDM 논문 식 (19) 뒤의 조건](https://arxiv.org/pdf/2204.12798#page=9)을
사용하며, `N`이나 `c1`이 바뀌면 이 조건을 재검토한다. OTFS는
[각 슬롯에 붙이는 CP](https://www.mathworks.com/help/comm/ug/otfs-modulation.html)를
채택한다. 프레임 전체에 CP 하나만 붙이는 RCP 구성과 구분한다.

`cyclic_prefix.py`의 공통 함수는 끝 샘플을 그대로 복사하고, 크기 조절이나
프레임 전력 재정규화를 하지 않는다. CP 에너지는 복사된 샘플의 제곱 크기 합으로
별도 기록한다. **같은 CP 길이가 같은 CP 에너지까지 보장하지는 않는다.**
데이터 `E_s=1`, 총 파일럿 에너지, 데이터 심볼 기준 `Eb/N0` 잡음 규칙은 유지한다.
파일럿·보호칸 25%의 분모는 계속 유효 격자 16,384칸이며, CP는 별도 시간 비용이다.

```powershell
python check_cyclic_prefix.py
```

CP 추가·제거, 에너지 집계, 정적 3경로의 선형 채널과 슬롯별 순환 채널의 일치를
검증했다. 상대 채널 계산 오차는 약 `1.06e-16`, CP를 4샘플로 줄인 비교용 사례의
불일치 오차는 약 `0.01295`다. 이 값은 파형 상대 오차이며 BER이 아니다.
AFDM의 CP/CPP 등가성과 OTFS의 CP 포함 복원도 허용오차 `1e-12` 이내였다.
기존 `check_otfs_transform.py`의 CP 없는 기본 변환 검증도 통과했다.

첫 단일경로 LOS + AWGN 기준 실험과 공통 도플러 완전 보정 가정은 유지한다.
이 CP 결정은 후속 3경로 단계의 설계다. 해당 단계의 도플러 보정 정책과 추정·등화
수치 설정은 계속 미정이며, DD-a-OFDM의 기존 DD-ML/TF 선형 MMSE 선정은 유지한다.
이번에는 공통 CP 함수와 OTFS 연결을 구현·검증했고, 다른 파형의 전체 송수신기와
BER 실험은 계속 구현할 항목이다.

## AFDM의 첫 블록 구성

AFDM은 **256점 IDAFT를 한 블록에 적용하고, 프레임마다 64블록을 연속으로
전송**한다. 수신기는 각 블록에 대응하는 256점 DAFT를 사용한다. 변환은
앞서 정한 유니터리 정규화를 따른다. 비교 기준 OFDM의 유효 심볼 단위와
AFDM의 유효 블록 단위를 다음처럼 맞춘다.

| 방식 | 송신 변환 단위 | 프레임당 개수 | 한 단위의 유효 샘플 수 |
| --- | --- | ---: | ---: |
| OFDM | 256점 IFFT | 64심볼 | 256 |
| AFDM | 256점 IDAFT | 64블록 | 256 |

60 MHz 샘플링에서 두 방식 모두 한 단위의 유효 길이는 약 4.267 µs,
프레임 전체는 16,384샘플이며 CP 등을 제외하면 약 0.273 ms다. AFDM의
`c1`, `c2` 선정식에 사용하는 블록 길이는 **`N_AFDM = 256`**이며,
전체 프레임 샘플 수 16,384와 구분한다. 첫 기준 실험에서는 프레임 전체를
한 번에 처리하는 16,384점 DAFT 구성을 채택하지 않는다.

`c1`, `c2`의 초기값과 위의 후속 3경로 CP 규칙을 정했다. 파일럿 배치 및
채널 추정·등화 세부 사항은 아직 정하지 않았다. 같은 블록 시간만으로
모든 비교 조건이 동등해졌다는 뜻은 아니다. BER용 AFDM 송수신기는 아직
구현하지 않았으며, 아래의 rank 점검은 별도의 수치 진단이다.

### c1의 설계 기준

`c1`은 **선택한 통과 구간 전체의 보정 전 공통 LOS 도플러 최대 절댓값**을
기준으로 설계했다. 채택한 지원 범위 안에서 첫 기준 실험,
저·고도플러 시점, 프레임 및 `Eb/N0`별로 같은 값을 고정해 사용한다.
매 시점의 실제 도플러에 맞춰 `c1`을 다시 조절하지 않는다. 이후 채널의
설계 범위를 변경하면 파라미터도 명시적으로 재검토한다.

현재 고정 궤도와 지상국, 11.7 GHz를 사용해 통과 구간을 0.25초 간격으로
탐색하고 양 끝점을 포함하면, 최대 절댓값은 **약 261.029 kHz**이며 이탈
시점인 `2026-07-29 07:51:02.674 UTC`에서 나타난다. 0.125초 간격으로도
같은 반올림 결과를 확인했다. 경사거리 변화율은 각 시각의 앞뒤 0.5초,
총 1초 간격의 중앙차분으로 계산했다. 이는 해당 통과의 수치적 추정값이며
모든 Starlink 통과의 최대값이나 실측값은 아니다.

이때 AFDM의 블록 기준 도플러 간격은 `F_s / N_AFDM = 234.375 kHz`이며,
최대 절댓값은 약 **1.11372416칸**이다. 이를 전체 64블록 프레임의 명목 DD
격자 간격과 구분한다. 전체 프레임의 간격은 CP가 없으면 약 3.66 kHz,
후속 CP 5샘플을 적용하면 약 3.592 kHz다.

정규화된 도플러를 `nu = alpha + a`로 나누며, `alpha`는 정수이고 분수 성분은
`-0.5 < a <= 0.5`를 만족한다. 현재 설계 범위에서 정수 성분의 최대 절댓값은
**`alpha_max = 1`**이다. 매 시점의 실제 도플러가 항상 1칸이라는 뜻은 아니다.
분수 도플러 여유의 초기값은 **`xi_nu = 1`**로 정했다.
[AFDM 논문 III-E절 식 (43)](https://arxiv.org/pdf/2204.12798#page=13)을 적용해
다음 값을 사용한다.

```text
c1 = (2 * (alpha_max + xi_nu) + 1) / (2 * N_AFDM)
   = (2 * (1 + 1) + 1) / (2 * 256)
   = 5/512 = 0.009765625
```

이는 합의한 초기 설계값이며 최적성이나 BER 성능을 검증한 값은 아니다.
`xi_nu = 1`은 분수 도플러의 영향이 한 칸 안에 모두 들어간다는 보장이나
수신기에서 주변 성분을 잘라내라는 설정이 아니다. 채널에는 실제 분수
도플러를 유지하며, 파일럿·보호칸 배치와 수신기 근사는 별도로 논의한다.
기존 3경로 통제 프로파일의 최대 초과 지연 **5샘플(60 MHz에서 약 83.3 ns)**은
후속 경로 분리·블록 내 수용 조건을 검토할 때 사용한다. 다중경로와 수신기
처리를 도입할 때 여유의 적절성을 확인한다. 첫 도플러 완전 보정 LOS + AWGN
실험으로는 이 여유의 도플러 대응 성능을 판단할 수 없다.

이 설계 기준을 사용해도 첫 LOS + AWGN 기준 실험에서는 실제 공통 도플러를
완전히 보정해 잔여값을 **0 Hz**로 둔다. 새로운 경로별 도플러나 미보정
실험 조건을 추가한 것은 아니다. 날짜·궤도·반송파·지상국 또는 AFDM의
샘플링·블록 길이가 바뀌면 지원 범위와 정규화된 도플러를 다시 계산한다.

### c2의 선정과 3경로 rank 점검

사용자가 구체적인 값의 선정을 위임하여 **`c2 = sqrt(2) / N_AFDM^2`**를 선택했다.
현재 `N_AFDM = 256`이므로 다음 값을 사용한다.

```text
c2 = sqrt(2)/65536 = 0.000021579186437577746 (수치 근삿값)
```

[AFDM 논문 IV절·VII절·부록 A](https://arxiv.org/pdf/2204.12798)는 경로 분리 등
논문의 조건 아래에서 신호 차이 행렬의 rank를 확보하는 무리수 `c2` 선택을
설명한다. 위의 구체적인 식은 이를 참고한 이번 실험의 설계 선택이다.
`N_AFDM^2`로 나누면 블록 내 심볼 인덱스 `m`에 대한 `c2*m^2`의 크기를
대략 일정한 규모로 유지할 수 있다. 최적 BER을 보장하는 식으로 해석하지 않는다.
정확한 설계식은 무리수이며, 컴퓨터에서는 배정밀도 근삿값으로 계산한다.

rank 조건은 서로 다른 송신 벡터의 차이 `delta = x - x' != 0`에 대해
`Phi(delta) = [H_1*delta, ..., H_P*delta]`의 열 rank가 경로 수 `P`가 되는 것이다.
계획한 **LOS + 반사 2개, 지연 0·2·5샘플**에서는 `Phi`가 **256행 3열**이고
목표 rank는 **3**이다. DAFT 변환 자체는 유니터리이며, 그 변환 행렬의 rank와
위 신호 차이 행렬의 rank를 구분한다. 첫 단일경로 기준 실험부터 후속 3경로
조건까지 같은 `c2`를 프레임·`Eb/N0`·저/고도플러 시점에 걸쳐 고정해 사용한다.
블록 길이나 지연·도플러 설계 범위를 바꾸면 파라미터를 명시적으로 재검토한다.

`check_afdm_rank.py`는 이상적인 순환 지연 블록에서 경로별 이득을 제외한
`H_i`를 구성해 수치 점검한다. 이는 충분한 보호구간으로 순환 블록을 구현한
경우의 진단 모델이다. 합의한 CP와 선형 채널의 관계는 위의 CP 점검에서 별도로
검증했고, 실제 채널 추정·등화기의 세부 사항은 계속 미정이다.
잔여 공통 도플러는 0 Hz로 두며, 새로운 경로별 도플러를 추가하지 않는다.

```powershell
python check_afdm_rank.py
```

시드 `20261103`으로 단일 위치 차이 256개, 두 위치 차이 1,024개, 무작위 조밀
16-QAM 차이 1,024개와 주기·comb·위상 패턴 21개를 검사했다. 총 **2,325개**에서
모두 상대 SVD 문턱값 `1e-10` 기준 **rank 3**이며, 관측한 최소 특잇값 비율
`sigma_min/sigma_max`는 약 **0.57735**다. 이 점검은 모든 가능한 송신 벡터 쌍에
대한 증명이나 BER 실험이 아니다. 첫 단일경로 기준 실험으로 3경로 다이버시티를
판단하지 않으며, 경로 크기가 고정된 LOS 우세 통제 모델에서 경로 수만으로
다이버시티 차수가 3이라고 주장하지 않는다.

## OTFS의 첫 송수신 구조

**OFDM 기반 OTFS와 직사각형 송수신 펄스**를 채택했다. 데이터는 지연 256칸 ×
도플러 64칸에 배치하고, ISFFT로 주파수 256칸 × 시간 64칸으로 변환한다.
각 시간 슬롯의 256점 IFFT가 송신 시간 파형을 만든다. 수신기는 슬롯별 FFT와
SFFT로 DD 관측값을 얻고, 이후 DD 선형 MMSE 등화·심볼 판정을 수행하는 방향으로
정했다. 추정 채널행렬의 구성과 처리 범위 및 구현은 계속 논의한다.
[MathWorks의 OTFS 설명](https://www.mathworks.com/help/comm/ug/otfs-modulation.html)을
참고하되, 예제의 패딩·채널·파일럿·배율 대신 이번에 합의한 조건과 유니터리
정규화를 사용한다.

배열은 지연 또는 주파수를 행, 도플러 또는 시간을 열로 둔다.

| 단계 | 배열의 행 | 배열의 열 | 크기 |
| --- | --- | --- | --- |
| DD 입력 | 지연 `l` | 도플러 `k` | 256 × 64 |
| ISFFT 출력 | 주파수 `m` | 시간 슬롯 `n` | 256 × 64 |
| 시간 파형 | 슬롯 내 샘플 `q` | 시간 슬롯 `n` | 256 × 64 |

```text
X_tf = FFT_delay(IFFT_Doppler(X_dd))        # ISFFT
s[q,n] = IFFT_frequency(X_tf)[q,n]          # 슬롯별 OFDM 변환
Y_tf = FFT_sample(r[q,n])
Y_dd = FFT_time(IFFT_frequency(Y_tf))       # SFFT
```

각 FFT/IFFT는 축 길이의 제곱근으로 정규화한다. CP 추가 전 유효 신호의 직렬화
인덱스는 `q + 256*n`으로 각 슬롯의 256샘플을 연속 배치한다. CP를 포함한 실제
스트림의 유효 샘플 위치는 위 공통 보호구간 절의 시간축을 사용한다.
변환 내부에 `fftshift`를 넣지 않는다.
유효 샘플 수는 **16,384**, 보호구간 제외 유효 프레임 시간은 약 **0.273 ms**로
공통 기준과 같다. 직사각형 펄스는 유효 슬롯의 시간창 선택이며, 실제 RF 필터나
점유 대역폭 마스크를 정한 것은 아니다.

`otfs.py`는 ISFFT/SFFT와 변조·기저 복조를 제공한다. 기본 `cp_length=0`은 기존
유효 신호만 처리하며, 후속 3경로 단계의 `cp_length=5`는 슬롯별 CP를 내부에서
추가·제거한다. 수신 입력의 시간 정렬은 호출자가 처리한다. 공통 CP 및 파일럿
자원·총 에너지 예산과 아래의 DD 파일럿 마스크를 적용한다.
알려진 파일럿은 `64+0j`로 고정했다. DD 선형 MMSE를 등화기 종류로 정했으며,
채널 추정법·행렬 구성·처리 범위와 심볼 판정 구현은 계속 미정이다.
이번 구현으로 새로운 동기화 가정이나 전체 채널 지식을 부여하지 않는다.

```powershell
python check_otfs_transform.py
```

이 점검은 3×2 및 4×5 격자의 직접 이중합 수식과 FFT 구현을 비교하고,
256×64 격자에서 복원·에너지 보존·직사각형 펄스의 역 Zak 표현과의 일치를
확인한다. 시드 `20261103`, NumPy 2.3.5에서 무작위 16-QAM 격자 8개와 DD
임펄스 4개를 검사했다. 최대 상대 복원 오차는 약 `5.15e-16`, 에너지 오차는
약 `4.45e-16`, 역 Zak 표현과의 차이는 약 `1.40e-14`로 상대 허용오차 `1e-12`
이내였다. 잡음이나 채널을 적용한 BER 실험은 아니다.

## DD-a-OFDM의 초기 수신 구조

참고 구조는 [DD-a-OFDM 논문 v2](https://arxiv.org/pdf/2508.04253v2)의 II-B절·그림 1과
IV절을 기준으로 기록한다. 확인한 버전은 2026-05-10 개정본이다.
송신은 공통 256개 부반송파 × 64개 시간 심볼의 OFDM 구조를 유지하고,
기존 공정성 원칙에 따라 OFDM과 같은 TF 파일럿 위치를 사용한다.
논문의 구체적인 파일럿 간격이나 5경로 설정을 이번 실험에 복사하지 않는다.

논문의 수신 흐름은 **TF 파일럿 관측 → DD 채널 파라미터 추정 → TF 채널행렬
재구성 → TF 등화·QAM 판정**이다. DD 영역은 채널 추정에 사용하고, 데이터의
등화는 TF 영역에서 수행한다. 송신 데이터에 OTFS의 ISFFT를 추가하는 구조는 아니다.
같은 TF 심볼·파일럿·프리픽스·펄스를 넣으면 OFDM과 DD-a-OFDM의 송신 파형은
같으므로, 두 방식의 BER 차이는 송수신 방식 비교에 포함된 추정·수신 처리 차이로
해석한다.

다음 알고리즘 조합을 **첫 구현 기준으로 확정**했다.

- **DD 채널 추정:** IV-A절 Algorithm 1의 ML 추정. 경로별 지연·도플러를 번갈아
  갱신하고, 복소 이득은 함께 LS 갱신하는 alternating projection 방식을 사용한다.
- **TF 등화:** IV-B절 식 (43)–(44)의 ICI를 포함한 전체 채널행렬 선형 MMSE. 우리 격자에서는
  시간 심볼마다 256×256 행렬을 구성하며, 프레임에는 64개 시간 심볼이 있다.

ML은 파일럿 관측으로 경로의 지연·도플러·복소 이득을 추정하는 단계이며,
추정값으로 TF 채널행렬을 구성한다. 선형 MMSE는 그 추정 채널과 수신 데이터를
이용해 심볼을 복원하는 단계다. QAM 판정과 비트 복원은 그 뒤에 수행한다.

경로 수 정보는 위의 공통 수신 정보 규칙에 따라 **첫 3경로 비교에서 알려준다**.
채널 생성기에 LOS + 반사 2개를 설정한 것과 수신기가 경로 수를 아는 것은
별도 가정이며, 이번에는 이를 네 방식에 같은 가용 정보로 명시했다.
논문의 Algorithm 1은 추정 경로 수를 입력받으며, IV-A절은 문턱값에 의한 경로 수
판별도 설명한다.

초기 3경로 비교에서는 경로 수 `P=3`만 공통으로 제공하고, 실제 지연·도플러·복소
이득은 파일럿으로 추정한다. 경로 수 판별은 후속 확장으로 분리한다. 알고리즘
조합은 위와 같이 정했으며, 수신기의 나머지 정보 조건과 수치 설정은 계속 미정이다.

OFDM/DD-a-OFDM의 파일럿 간격은 주파수 2칸 × 시간 2블록으로 정했다.
파일럿 값·방식 내 균등 에너지 배분은 정했다. 탐색 범위와 분수 격자 보정, 반복 횟수·종료 기준,
잡음 분산 정보 및 다른 방식의 등화 조건은 계속 논의한다. 기존 단일경로 기준
실험과 공통 도플러 보정, 3경로 생성 프로파일의 추가 도플러 0 Hz는 유지한다.
이 절은 참고 구조와 합의한 초기 알고리즘을 기록한 것이며, DD-a-OFDM 수신기 구현이나 BER
실험을 수행한 것은 아니다.

## 공통 등화기와 채널 추정법의 선정 상태

후속 파일럿 기반 3경로 A/B 비교의 등화기 종류는 네 방식 모두 **선형 MMSE**로
정했다. 각 수신기가 파일럿에서 얻은 채널 추정값으로 행렬을 구성해 사용한다.
공통 `P=3` 사전정보와 LOS 공통 도플러 완전 보정은 유지하며, 실제 경로 지연·추가
도플러·복소 이득의 정답을 수신기에 제공하는 가정은 추가하지 않는다.

| 방식 | 구체적인 채널 추정법 | 합의한 등화 영역·종류 |
| --- | --- | --- |
| OFDM | BEM 기반 LS 검토 중, 추정 구간은 한 프레임 64블록으로 확정 | TF 선형 MMSE |
| AFDM | 미정, DAFT 파일럿 관측 기반 후보에서 선택 | DAFT 선형 MMSE |
| OTFS | 미정, DD 파일럿 관측 기반 후보에서 선택 | DD 선형 MMSE |
| DD-a-OFDM | 기존 DD-ML alternating projection 초기 조합 선정 | 기존 TF 행렬 선형 MMSE |

[DD-a-OFDM 논문 V-D절](https://arxiv.org/pdf/2508.04253v2#page=13)은
OFDM과 DD-a-OFDM에 ICI를 고려하는 MMSE 등화기를 함께 사용한다.
네 방식 모두 선형 MMSE를 쓰는 것은 이번 실험에서 합의한 공통 기준이다.
OFDM이 ICI 항을 어떻게 추정할지, 다른 방식의 행렬 구성과 처리 범위,
파일럿 성분 처리·데이터 공분산·잡음 분산 정보와 수치 풀이 설정은 계속 정해야 한다.
같은 등화기 이름만으로 모든 수신 조건이 같아지는 것은 아니다.
기존 DD-a-OFDM의 심볼당 256×256 TF 행렬 64개 구성은 유지한다.
등화기 종류만 합의한 상태이며, 실제 수신기나 BER을 구현·실행한 결과는 아니다.

OFDM은 BEM 기반 LS 후보의 처리 구간까지 정했으며, 기저·차수와 추정 가능성은
계속 검토한다. AFDM·OTFS 추정법은 이번 실험에서 아직 선택하지 않았다.
관련 채널 추정·검출 방법은 문헌에 존재한다.
공통 설정은 `scenario.json`의 `receiver_equalization_policy`에 기록한다.

### OFDM BEM 추정 구간의 결정 과정 — 2026-11-04

**검토 중인 BEM 기반 LS의 채널 추정 구간을 한 프레임의 64개 OFDM 블록으로
확정**했다. BEM의 기저 함수·개수와 전체 추정 알고리즘의 충분성은 다음에 검토한다.

| 검토한 범위 | 현재 조건에서의 이점과 제약 |
| --- | --- |
| 한 블록씩 독립 추정 | 국소 모델이 짧아지지만 파일럿이 없는 블록에는 이웃 블록의 정보·보간 또는 별도 모델이 필요함 |
| 한 프레임의 64블록 공동 추정 — 선택 | 프레임의 32개 파일럿 시간 위치를 모아 시간변화 모델을 추정할 수 있으며, 한 프레임 안에서 경로 파라미터를 유지하는 현재 채널 모델과 연결하기 자연스러움 |

선택 과정에서 확인한 수치는 다음과 같다.

- OFDM 유효 블록 256샘플 + CP 5샘플 = 261샘플, 60 MHz에서 **4.35 µs**
- 64블록 = **16,704샘플, CP 포함 278.4 µs**
- TF 파일럿은 시간 인덱스 `0,2,...,62`의 32개 위치와 주파수 128개 위치에 존재하므로,
  프레임 안의 활성 파일럿 관측은 **4,096개**
- 시간 인덱스 `1,3,...,63`에는 직접 파일럿이 없으므로, 한 블록만 독립적으로 보는
  파일럿 기반 추정만으로는 프레임 전체를 처리할 수 없음

현재 채널은 한 프레임 안에서 경로 지연·크기·초기 위상 파라미터를 유지하고,
경로별 도플러가 만드는 결정적 위상 변화는 반영한다. 따라서 프레임 전체의
파일럿으로 하나의 **시간변화 모델**을 추정하고, 각 블록의 실제 샘플 시각에서
이를 평가해 채널을 얻는 방향으로 정했다. 시간축에는 CP 구간도 포함한다.
독립 시행에서는 반사경로의 초기 위상을 다시 뽑으므로, 서로 다른 프레임의
관측을 하나의 연속 채널로 묶지 않는다.

이 결정은 수신기의 **채널 추정 구간**에 관한 것이다. 송신은 기존 256점 OFDM
블록 64개 구성을 사용하며, 데이터 등화기의 행렬 크기나 공동 처리 범위는 계속
정해야 한다. 파일럿 자원·에너지 예산과 실제 경로 파라미터를 수신기에 주지 않는
정보 규칙도 유지한다.

긴 구간을 쓰는 데 따른 모델링 부담도 기록한다. 최대 잔여 도플러 크기
46,875 Hz의 경로는 명목 프레임 시간 동안 `46,875 * 278.4e-6 = 13.05`회전한다.
따라서 구간 전체의 채널을 상수로 두는 대신 이 변화를 표현할 기저와 개수가
필요하다. 현재 선택이 최적 길이라는 성능 검증은 아직 없으며, 다음 단계에서
모델 근사 오차·추정식의 식별 가능성과 조건수·파일럿 없는 블록의 오차를 확인한다.
특히 마지막 63번 블록의 추정도 확인한다.

[여러 OFDM 블록에 걸친 BEM 및 LS 추정 연구](https://www.jstage.jst.go.jp/article/transcom/E95.B/10/E95.B_3252/_article/-char/en)는
방법군의 참고 근거다. **64블록이라는 수치는 이번 프로젝트의 프레임·파일럿·채널
설정에 근거한 선택**이며, 참고 논문에서 정한 값을 복사한 것이 아니다.
수신기 구현이나 BER 결과를 새로 얻은 결정은 아니다.

### 추후 비교 발표에 포함할 BEM 설명

네 가지 송수신 방식의 비교 발표를 준비할 때 **BEM(Basis Expansion Model)**을
짧게 소개한다. 시간에 따라 변하는 채널을 소수의 기본 함수와 계수의 합으로
근사한다는 개념과, 파일럿으로 계수를 LS 추정해 ICI를 포함한 TF 채널행렬을
구성한 뒤 선형 MMSE 등화에 활용하는 후보 흐름을 설명한다.
[BEM 기반 LS 추정과 선형 MMSE 등화 연구](https://www.jstage.jst.go.jp/article/transcom/E95.B/10/E95.B_3252/_article/-char/en)를 참고한다.
현재 BEM 기반 LS는 OFDM 채널 추정의 **검토 후보**이며, 한 프레임 64블록의
추정 구간은 확정했다. 기저 함수·차수와 현재 파일럿 배치에서의 추정 가능성은
아직 선정·검증하지 않았다. 위의 결정 과정도 발표 준비 시 함께 참고한다.
이는 나중에 발표에 넣을 내용의 메모이며, 지금 발표 파일을 제작하는 작업은 아니다.

## 파일럿 비교 원칙

네 방식의 파일럿 위치는 각 방식에 맞게 둘 수 있지만, 프레임에서
**파일럿과 그 때문에 비워 두는 보호칸이 차지하는 비중**은 동일하게 맞춘다.
파일럿 신호에 할당한 **총 에너지**도 동일하게 맞춘다. OFDM과 DD-a-OFDM은
같은 시간–주파수 파일럿 위치를 사용하되, DD-a-OFDM의 수신기는 이를 DD
영역에서 처리한다. AFDM은 고유한 DAFT 영역, OTFS는 지연–도플러 영역의
파일럿 배치를 사용한다. 파일럿 보호칸은 앞서 0개로 정한 주파수 격자의
양끝 보호칸과 별개의 자원이다. 아래의 공통 비율·총 에너지 예산은 확정했으며,
네 방식의 배치와 알려진 고정 파일럿 값·방식 내 균등 에너지 배분은 아래와 같이 정했다.
각 추정기의 수치 설정과 실제 추정 성능은 계속 논의·검증한다.
첫 단일경로 기준 실험의 공통
도플러 보정은 완전한 주파수 정보로 수행하므로, 도플러 획득용 프리앰블을
채택한 것은 아니다. 실제 도플러 추정·추적 방식은 후속 논의 대상으로 남긴다.

### 합의한 공통 파일럿 예산

다음 수치를 **후속 첫 파일럿 기반 3경로 비교의 초기 예산으로 합의**했다.
기준 단위는 보호구간을 제외한 공통 **256×64 = 16,384칸**의 유효 격자다.
구체적인 배치와 누설·추정 성능의 충분성 검증은 계속 진행할 항목이다.

| 항목 | 합의한 초기 예산 |
| --- | ---: |
| 파일럿 + 파일럿 보호·예약칸 | 25% = 4,096칸 |
| 데이터 | 75% = 12,288칸 |
| 총 파일럿 에너지 | 네 방식 모두 `E_p = 4,096 E_s` |
| 데이터 심볼 평균 에너지 | 기존 `E_s = 1` 유지 |

**파일럿과 보호칸을 합친 비용**, **총 파일럿 에너지**를 프레임 단위로 맞춘다.
OFDM과 DD-a-OFDM은 TF 파일럿 위치·값·에너지 배분을 같게 두고, AFDM은 DAFT,
OTFS는 DD 영역에서 배치한다. 서로 다른 기저의 파일럿 좌표까지 같게 만들지는
않는다. 실제로 쓰는 파일럿 수가 `N_p`라면 균등 배분 시 개별 파일럿 에너지는
`E_p/N_p`다. 파일럿 수가 다른 방식은 개별 파일럿의 세기도 달라진다.
결과에는 실제 파일럿 수·보호/예약칸 수·데이터 수·총 파일럿 에너지도 따로 기록한다.

25%의 근거는 조건부 자원 계산이다. [AFDM 논문의 embedded pilot 배치식](https://arxiv.org/pdf/2204.12798#page=24)을
매 256점 블록에 적용하고 현재 설계 범위 `l_max=5`, `alpha_max=1`, `xi_nu=1`을
사용하면 파일럿과 보호칸은 `2*(5+1)*(2*(1+1)+1)-1 = 59`칸, 약 **23.05%**다.
이를 64칸, 즉 25%로 올려 잡아 초기 예산으로 정했다. 블록마다 논문형 단일 파일럿을
넣고 보호칸을 5칸 확장한 배치를 아래와 같이 선택했다.
59칸이 모든 AFDM 배치의 최소값이라는 뜻은 아니다.
현재 분수 도플러 여유에서 실제 누설과 추정 성능도 검증해야 한다.

합의한 에너지 예산에서는 데이터의 기대 에너지 12,288과 파일럿 에너지 4,096의
합이 16,384가 되어, 유효 격자의 평균 에너지 규모를 맞추기 쉽다. 모두 정규화된
시뮬레이션 단위이며, 개별 프레임을 측정해 다시 전력을 맞추지는 않는다.
CP/CPP의 샘플 수·에너지는 따로 계산한다.

다중경로의 공통 LOS 완전 보정과 잔여 도플러 범위는 정했으며,
네 방식의 첫 배치와 알려진 파일럿 값·균등 에너지 배분도 아래와 같이 정했다.
피크 전력 조건과 수신기 성능 검증은 계속 검토할 항목이다.
보호칸을 포함한 25%가 각 방식의 최적 비율이거나 모든 미래 도플러 조건에서
충분하다고 검증한 것은 아니다. 고정 정보 비트 수 조건은 유지하며,
마지막 프레임의 데이터·패딩 집계는 계속 설계할 항목이다.

이 예산에서 16-QAM 데이터를 모두 채운 프레임의 데이터 비트 수는
`12,288 × 4 = 49,152`다. 기존 측정량 10,485,760비트를 유지하면 완전한 데이터
프레임 213개와 나머지 16,384비트가 필요하므로, 예산상 214번째 프레임까지
필요하다. 이는 자원 계산이며, 실제 마지막 프레임의 배치·패딩·측정 처리는
아직 정하지 않았다. 파일럿·보호칸·패딩을 BER의 정보 비트 수에 포함하지 않는다.

### OFDM과 DD-a-OFDM의 공통 TF 파일럿 배치

두 방식은 **주파수 2칸마다 × 시간 2블록마다** 같은 위치에 파일럿을 둔다.
재현을 위한 좌표 원점은 0 기반 배열의 `(주파수 0, 시간 0)`으로 둔다.
즉 주파수 인덱스 `0,2,...,254`와 시간 인덱스 `0,2,...,62`의 교차점이 파일럿이다.
나머지 TF 칸에는 데이터를 넣는다. A 및 모든 B 단계에서 같은 배치를 사용한다.

| 항목 | 두 방식 각각의 프레임당 값 |
| --- | ---: |
| 파일럿 주파수 행 × 시간 열 | 128 × 32 |
| 활성 파일럿 | 4,096칸 |
| 파일럿 전용 보호·예약칸 | 0칸 |
| 데이터 | 12,288칸 |
| 파일럿 + 파일럿 보호·예약칸 비중 | 25% |
| 총 파일럿 에너지 | 기존 `4,096 E_s` 유지 |

CP 5샘플은 별도의 시간 보호구간으로 유지한다. 두 방식은 같은 고정 QPSK
파일럿 값을 쓰며, 각 활성 파일럿의 에너지는 균등하게 `1 E_s`로 둔다.

파일럿의 주파수 간격은 468.75 kHz, CP 포함 시간 간격은 8.7 µs다.
[DD-a-OFDM 논문의 Remark 1](https://arxiv.org/pdf/2508.04253v2#page=6)의
균일 TF 샘플링 조건을 적용하면 기본 지연 주기는 약 2.133 µs,
대칭 도플러 범위는 약 ±57.47 kHz다. 현재 초과 지연 0·2·5샘플과
최대 잔여 도플러 ±46.875 kHz는 이 기본 범위 안에 있다.
이는 자원·기본 샘플링 범위 확인이며, 분수 도플러의 누설·실제 추정 오차·BER까지
검증한 것은 아니다. 네 방식의 실제 추정 성능은 계속 확인한다.

### AFDM과 OTFS의 파일럿·보호·예약칸 배치

AFDM은 매 256칸 DAFT 블록에서 파일럿 인덱스를 0으로 둔다. 순환 방향으로
앞 31칸(`225..255`), 뒤 32칸(`1..32`)은 0으로 비우고,
나머지 `33..224`의 192칸에 데이터를 넣는다. 이를 64개 블록에 반복한다.
[AFDM embedded pilot 방식](https://arxiv.org/pdf/2204.12798#page=19)을 바탕으로
현재의 59칸 계산보다 보호칸을 5칸 늘린 구성이다. 분수 도플러의 꼬리 누설은
유지되므로, 채널 추정기에서 실제 영향을 검증해야 한다.

OTFS는 0 기반 `(지연 128, 도플러 32)`에 파일럿 1칸을 둔다.
지연 `96..159`의 64칸 × 도플러 `0..63`의 전체 64칸을 비데이터 영역으로
예약하고, 파일럿을 제외한 나머지는 0으로 둔다. 이 중 지연 `123..133`의
11개 행이 [분수 도플러 full-guard 방식, 식 (7)](https://arxiv.org/pdf/1808.08360#page=4)의
`(2*5+1)*64 = 704`칸에 해당한다. 파일럿을 제외한 기본 보호칸은 703개이며,
나머지 3,392칸은 같은 25% 비교 조건을 맞추는 추가 예약칸이다.
25% 전체가 OTFS에 필요한 최소 보호영역이라는 뜻은 아니다.

| 방식 | 활성 파일럿 | 보호칸 | 추가 예약칸 | 데이터 | 활성 파일럿 한 칸의 에너지 |
| --- | ---: | ---: | ---: | ---: | ---: |
| OFDM | 4,096 | 0 | 0 | 12,288 | `1 E_s` |
| DD-a-OFDM | 4,096 | 0 | 0 | 12,288 | `1 E_s` |
| AFDM | 64 | 4,032 | 0 | 12,288 | `64 E_s` |
| OTFS | 1 | 703 | 3,392 | 12,288 | `4,096 E_s` |

네 방식 모두 **파일럿 + 보호 + 예약칸은 4,096칸**, **총 파일럿 에너지는
`4,096 E_s`**다. 방식 안에서는 모든 활성 파일럿에 에너지를 균등하게 나눈다.
OTFS는 파일럿 하나이므로 에너지가 4,096이며, `E_s=1`에서 복소 진폭 크기는
64로 정해지며, 위상은 0으로 두어 파일럿 값을 `64+0j`로 선택했다.

### 합의한 고정 파일럿 값과 비교 해석

기본 위상값은 `q ∈ {1, j, −1, −j}`의 QPSK 값으로 둔다.
OFDM/DD-a-OFDM은 4,096개 고정 위상값을 같은 순서로 사용하고,
AFDM은 이 기본 위상열의 앞 64개를 가져와 크기만 8배로 보낸다.
따라서 각 방식의 알려진 파일럿은 다음과 같다.

| 방식 | 알려진 파일럿 값 | 파일럿 하나의 에너지 |
| --- | --- | ---: |
| OFDM·DD-a-OFDM | `q` | `1 E_s` |
| AFDM | `8q` | `64 E_s` |
| OTFS | `64+0j` | `4,096 E_s` |

위상열은 독립 로컬 RNG(`NumPy PCG64`, 시드 `20261103`)로 한 번 정해지는
재현 가능한 값이다. 프레임·독립 시행·`Eb/N0`·도플러 단계·궤도 시점에 걸쳐
같은 값을 재사용한다. 데이터와 무작위 채널 위상을 만드는 난수열은 소모하지 않는다.
시퀀스의 생성 규칙과 해시를 `scenario.json`에 기록했다.
송수신기가 아는 파일럿 값이며, 실제 채널 지연·경로별 도플러·이득의 정답을
수신기에 주는 것은 아니다. 데이터 변조는 기존 비부호화 Gray 16-QAM을 유지한다.

현재 비교는 **같은 자원·에너지 예산에서 각 파일럿 기반 송수신 설계의 BER을
비교**하는 것이다. 파형별 파일럿 수·기저·채널 추정·등화 방식의 영향도 결과에
포함된다. 총량을 맞췄다는 이유로 모든 BER 차이를 파형 자체에만 귀속하지 않는다.
이 고정 시퀀스는 합의한 초기 설계이며, 최적화된 파일럿이라는 주장은 하지 않는다.

유니터리 변환은 파일럿 성분의 에너지를 보존하므로, 이 동등성은
**CP를 붙이기 전 실제 유효 송신 시간 신호의 파일럿 에너지**에도 적용된다.
CP로 복사하는 에너지는 별도 집계하며, CP까지 합친 총 파일럿 성분 에너지가
자동으로 같아진다는 의미는 아니다. 이는 기존 CP 에너지 집계 원칙을 유지한 것이다.

### 배치 구현 및 검증 범위

`pilot_layouts.py`의 `build_masks`는 네 방식의 파일럿·보호·예약·데이터 마스크를 만든다.
`known_pilot_symbols`는 위의 합의한 고정 파일럿을 만든다. `build_grid`는
이를 기본값으로 사용해 호출자의 데이터를 각자의 기저에 배치한다.
검증용 파일럿을 명시적으로 전달할 수도 있지만 총에너지 4,096 조건을 확인하며,
값이나 진폭을 자동으로 바꾸지 않는다. 각 영역의 심볼은 열 우선(`order="F"`) 순서로 채운다.

```powershell
python check_pilot_layouts.py
```

합의한 고정 파일럿으로 재현성·기본 위상열 재사용·균등 에너지·칸 수·영역 분리·변환 왕복·실제 유효 송신 시간 신호의
에너지를 확인했다. 네 방식 모두 파일럿 에너지가 4,096이며,
변환 왕복의 최대 상대 오차는 약 `4.56e-16`이다.
현재 CP·정수 지연과 합의한 모든 잔여 도플러 단계에서 OTFS의 데이터 성분이
파일럿 관측 영역으로 새는 상대 노름은 약 `5.35e-17`이었다.
이 검사는 합의한 고정 파일럿 값을 사용한다.
AFDM의 분수 도플러 추정 누설, 네 방식의 채널 추정·등화·BER은 이 검사에 포함하지 않는다.

## 도플러 비교 계획

먼저 공통 도플러를 완전히 보정한 LOS 단일경로 + AWGN 기준 실험에서 네
파형의 BER을 비교한다. 기존에 정한 저·고도플러 두 시점은 궤도 기반 입력과
후속 비교를 위한 참조로 보존한다. 첫 기준 실험에서는 두 시점의 보정 후
잔여 공통 도플러가 모두 0 Hz이므로, 이를 서로 다른 도플러 스트레스 조건으로
해석하지 않는다. 두 시점을 모두 실행한다면 보정 일관성을 확인하는 용도다.
네 파형에는 동일한 수신 `Eb/N0`를 적용한다. 고도만을 기준으로 도플러 값을
가정하지 않고, 선택할 시점의 궤도에서 도플러를 계산한다. 따라서 우리가 정할 것은 두
대표 시각의 선택 기준이며, 도플러 수치는 임의로 정하지 않는다. 현재 통과
초안에서는 최고 고도각 시점(07:46:50.803 UTC)을 저도플러 조건으로,
고도각 10°의 이탈 시점(07:51:02.674 UTC)을 고도플러 조건으로 정했다.
첫 단일경로 기준 실험의 수신기는 이 공통 도플러를 완전히 보정한다.

후속 3경로 실험은 다음의 **A/B 통제 비교**로 정했다. B는 지연도 포함한다.

| 항목 | A: 정적 다중경로 | B: 지연 + 경로별 도플러 |
| --- | --- | --- |
| 경로·초과 지연·상대 전력 | 기존 3경로, 0·2·5샘플, 0·−10·−15 dB | A와 동일 |
| 공통 LOS 도플러 | 궤도에서 계산해 적용한 뒤 완전히 보정 | A와 동일 |
| 보정 후 경로별 도플러 | 세 경로 모두 0 Hz | LOS는 0 Hz, 반사경로의 차이는 단계적으로 증가 |
| 초기 위상·정규화·비트 수·자원/에너지 예산 | 기존 공통 조건 | 같은 시행의 A 및 네 방식과 동일 |

B는 실제 반사환경을 복원한 값이 아닌 **합성 도플러 민감도 실험**이다.
위성 궤도와 수신국 좌표만으로 반사경로 도플러를 확정하지 않는다.
최대 잔여 도플러 크기 `d = max_p |delta_f_p|`를 공통 부반송파 간격
`Delta_f = 234,375 Hz`로 나눈 비율 `epsilon = d/Delta_f`를 사용해 다음을 정했다.

| 조건 | 최대 잔여 도플러 / 부반송파 간격 | 최대 잔여 도플러 `d` |
| --- | ---: | ---: |
| A | 0% | 0 Hz |
| B-1 | 1% | 2,343.75 Hz |
| B-2 | 5% | 11,718.75 Hz |
| B-3 | 10% | 23,437.5 Hz |
| B-4 | 20% | 46,875 Hz |

A를 포함해 총 5개 초기 탐색 조건이다. 이 수치는 합의한 통제 실험용 선택이며,
실제 Starlink 반사경로 측정값이나 표준에서 정한 범위가 아니다.
`d`는 LOS 대비 최대 절댓값이며, 경로 전체의 양 끝 차이인 도플러 확산 폭
`max(delta_f_p)-min(delta_f_p)`과 구분한다. 각 단계에서 경로 순서
`[LOS, 반사 1, 반사 2]`의 잔여 도플러를 **`[0, +d, -d]`**로 정했다.

| 조건 | LOS | 반사 1: 지연 2샘플, −10 dB | 반사 2: 지연 5샘플, −15 dB |
| --- | ---: | ---: | ---: |
| A | 0 Hz | 0 Hz | 0 Hz |
| B-1 | 0 Hz | +2,343.75 Hz | −2,343.75 Hz |
| B-2 | 0 Hz | +11,718.75 Hz | −11,718.75 Hz |
| B-3 | 0 Hz | +23,437.5 Hz | −23,437.5 Hz |
| B-4 | 0 Hz | +46,875 Hz | −46,875 Hz |

반사 1은 양수, 반사 2는 음수로 모든 단계·시행·방식에서 유지한다.
이 배치의 전체 도플러 확산 폭은 `2d`이며, B-4에서는 93,750 Hz다.
기존 명시적 경로 프로파일은 A의 추가 도플러 0 Hz를 유지한다.
B의 경로별 벡터도 `scenario.json`에 확정값으로 기록했지만, 채널 생성기와
네 방식의 BER 실험은 아직 구현·실행한 것이 아니다.
도플러를 정수 DD 칸으로 반올림하지 않고 Hz 값을 그대로 사용한다.
공통 주파수의 정답만 보정에 제공하며, 실제 경로 지연·추가 도플러·복소 이득은
파일럿으로 추정한다. 공통 경로 수 사전정보 `P=3`은 유지한다.
초기 위상과 경로 크기는 같은 시행의 A/B 및 모든 단계에서 재사용하지만, B의
경로별 도플러가 만드는 시간에 따른 위상 변화는 유지한다. 최종 파일럿 배치와
수신 설정도 단계마다 임의로 바꾸지 않으며, 적응 규칙이 필요하면 별도로 함께 정한다.
공통 도플러 보정 오차는 이 A/B에 포함하지 않는 별도 미선택 확장이다.
동일한 잔여 프로파일이라면 최고점·이탈 시점은 보정 후 같은 조건이므로,
B의 도플러 단계들이 새로운 비교 조건이 된다. 이 계획의 BER 실험은 아직 실행하지 않았다.

현재 시나리오 초안의 통과를 기준으로 경사거리의 1초 중앙차분과
`f_D ≈ -f_c (dR/dt)/c`를 적용하면, 고도각 10°의 진입 시점은 약 +260.9 kHz,
선택한 최고 고도각 시점은 약 +0.5 kHz, 최근접 시점은 약 0 kHz,
선택한 이탈 시점은 약 -261.0 kHz다.
이는 제공된 OMM 궤도와 지상국 좌표, 공통 대표 반송파 11.7 GHz에서
계산한 예측값이며, 실제 송신 신호를 측정한 값은 아니다. 통과 날짜·최소
고도각 자체는 아직 시나리오 초안이므로 변경하면 시각과 도플러를 다시 계산한다.

## 확정한 실험 목적

동일한 성균관대–STARLINK-5285 다운링크 조건과 동일한 수신 `Eb/N0`에서
OFDM, AFDM, OTFS, DD-a-OFDM 네 송수신 방식의 BER을 비교한다.
BER 비교 축은 수신 `Eb/N0`이며, 예비 탐색 범위와 간격은 아래에 정했다.

결과는 **가로축: 수신 데이터 심볼 기준 `Eb/N0`(dB), 세로축: BER**인 곡선으로
비교한다. `Eb/N0`는 바꿔가며 넣는 신호·잡음 조건이고 BER이 측정 결과다.
같은 `Eb/N0`에서 BER이 낮은 방식을 비교하며, 같은 곡선에서 목표 BER에 필요한
`Eb/N0`도 읽을 수 있다. 목표 BER의 값은 아직 정하지 않았다.
[BER 대 Eb/N0 분석](https://www.mathworks.com/help/comm/ref/biterrorrateanalysis-app.html)과
같은 축 구성이며, `Eb/N0`와 파형 샘플 전력 기준 SNR의 변환에는 변조·샘플링·
에너지 집계 조건을 반영해야 하므로 두 값을 같은 이름으로 기록하지 않는다.
[SNR과 Eb/N0의 변환](https://www.mathworks.com/help/comm/ref/convertsnr.html)도
변조 차수·부호율·샘플링 조건을 구분한다.

## 확정한 링크 방향과 대역

성균관대 지상국은 수신만 하며, 위성에서 지상국으로 오는 Ku 다운링크만
비교한다. Ku는 사용할 주파수 대역이고, 신호가 실제 차지하는 대역폭은
별도로 정한다. 네 방식의 공통 반송파 주파수는 11.7 GHz로 정했다.
이는 BER 비교를 위한 Ku 대역 대표값이며, STARLINK-5285가 해당 통과에서
실제로 사용한 채널 중심이라는 주장은 아니다. 명목 격자 대역폭은 아래와 같이
정했다. 첫 BER 비교에서는 가장자리 보호칸과 중앙 DC 빈 칸을 모두 두지 않는다.
실제 스펙트럼 점유 대역폭은 아직 정하지 않았다.

## 확정한 심볼 변조 방식

OFDM, AFDM, OTFS, DD-a-OFDM 모두 같은 16-QAM 심볼을 사용한다. 한 심볼에
4비트를 담는다. 네 방식에 넣는 데이터 심볼의 **평균 심볼 에너지는
`E_s = E[|s|²] = 1`**로 정규화한다. 이는 같은 크기 기준의 심볼로 네 파형을
비교하기 위한 상대적인 에너지 단위이며, 실제 송신전력을 1 W로 정한 것은 아니다.

정규화는 등확률의 16개 신호점 전체에 대한 평균을 기준으로 한 고정 배율이다.
각 심볼의 에너지가 모두 1이라는 뜻이나, 무작위 데이터 프레임마다 순간 평균을
다시 1로 맞춘다는 뜻은 아니다. 예를 들어 일반적인 정사각형 16-QAM에서
`I, Q ∈ {−3, −1, 1, 3}`이면 정규화 전 평균 에너지는 10이므로,
`s = (I + jQ) / √10`으로 평균 심볼 에너지를 1로 맞출 수 있다.

비트-심볼 매핑은 네 방식 모두 동일한 **Gray 매핑**으로 정했다. 정사각형
16-QAM의 수평·수직으로 이웃한 신호점끼리 1비트만 다르게 배치하여,
가까운 점으로 잘못 판단했을 때 발생하는 비트 오류를 줄인다. 오류 정정
부호화는 계속 적용하지 않는다.

`E_b`는 위 잡음 모델 절의 데이터 심볼 기준으로 정의하며, 이에 따른 심볼
기준 잡음 분산은 계산으로 정해진다. 파형 변환은 위의 유니터리 정규화로
통일하고, 첫 샘플링 격자는 60 MHz로 정했다. 필터와 파일럿 에너지 및
후속 실험의 샘플링 변경에 따른 신호·잡음 배율은 별도로 논의한다.
지금까지 네 파형에 넣을 데이터 심볼의 변조 방식·평균 에너지·비트 매핑을
공통으로 정했다.

## 수신 Eb/N0 탐색 계획

첫 BER 비교에서는 네 파형 모두에 같은 수신 `Eb/N0` 값 0, 5, 10, 15, 20,
25, 30 dB를 적용해 넓은 구간을 먼저 탐색한다. 이는 적은 측정 지점으로
BER 변화 구간을 찾기 위한 예비 범위이며, STARLINK-5285에서 측정하거나
링크 예산으로 계산한 SNR 범위가 아니다. 예비 결과에서 BER이 변하거나
파형 차이가 나타나는 구간을 골라 1~2 dB 간격으로 다시 측정한다. 정확한
세부 구간과 간격은 예비 결과를 보고 결정하고, 필요하면 시작·끝값도 확장한다.

## BER 측정량과 종료 기준

각 `Eb/N0`와 채널 조건에서 OFDM, AFDM, OTFS, DD-a-OFDM 모두
**10,485,760개의 정보·데이터 비트**를 측정한다. 모든 파형과 탐색 지점에
같은 비트 수를 적용하며, 오류 수에 따른 조기 종료는 하지 않는다. BER은
실제 측정한 데이터 비트 중 잘못 복구한 비트의 비율로 계산한다. 알려진
파일럿·프리픽스·보호구간·패딩은 데이터 비트 수와 오류 집계에서 제외한다.

모든 격자 칸이 비부호화 16-QAM 데이터라면 한 프레임은
`256 × 64 × 4 = 65,536`비트이므로, 이 측정량은 정확히 **160프레임**이다.
파일럿이나 예약칸을 도입하면 실제 데이터 비트 수에 맞춰 프레임 구성을 다시
계산하며, 네 방식의 공통 정보 비트 측정량은 유지한다. 이번 결정으로 구체적인
파일럿·보호구간 배치를 정한 것은 아니다.

약 1천만 비트는 실제 BER이 `10^-5`라면 평균 약 105개의 오류를 관측할 수 있는
초기 측정량이다. [BER 측정량과 오류 수에 관한 설명](https://www.mathworks.com/help/comm/ug/analyze-performance-with-bit-error-rate-analysis-app.html)의
약 100개 오류라는 기준을 정밀도 계획의 출발점으로 참고했다. 이는 실제 오류
수를 보장하거나 오류 100개에서 중단한다는 뜻이 아니다. BER이 `10^-6` 정도면
예상 오류가 약 10개에 불과하므로, 이보다 낮은 BER의 정밀한 비교에는 측정량을
다시 검토해야 한다.

결과에는 실제 측정 비트 수·오류 수·BER 추정값·신뢰구간을 함께 기록한다.
오류가 0개이면 측정 비트 수와 함께 **오류 미관측**으로 표시하고, 실제 BER이
정확히 0이라고 해석하지 않는다. 신뢰수준과 구체적인 신뢰구간 계산법은 아직
정하지 않았다. 실제 BER 측정과 실행시간 검증도 아직 수행하지 않았다.

## 대역폭 결정과 근거

네 방식의 공통 명목 격자 대역폭은 `B = N × Δf = 256 × 234.375 kHz = 60 MHz`다.
[Starlink Ku 신호 관측 연구](https://radionavlab.ae.utexas.edu/wp-content/uploads/starlink_structure.pdf)의
채널당 240 MHz와 같은 부반송파 간격을 유지하면서, BER 반복 계산의 부담을
줄이기 위해 격자 크기를 1024에서 256으로 줄였다. 이는 계산 편의를 위한
실험 설정이며 STARLINK-5285가 사용한 실제 대역폭이라는 뜻은 아니다.
명목 대역폭 기준 지연 분해능 `1/B`는 약 16.7 ns로, 240 MHz의 약 4.17 ns보다
낮다. 따라서 나중에 다중경로 채널을 정할 때 이 차이를 해석에 반영해야 한다.
첫 BER 비교의 왼쪽·오른쪽 가장자리 보호칸은 각각 0개로 정했다. 네 파형에
같은 규칙을 적용하고, 보호칸을 둔 경우는 이후 별도의 민감도 실험에서 살펴본다.
이는 계산 및 비교를 위한 단순화이며, 실제 송신 신호에 보호 대역이 없다는
주장은 아니다. 중앙 DC 칸도 비우지 않아 256개 주파수 칸을 모두 사용할 수
있다. DC를 비운 경우 역시 이후 별도로 비교한다. 데이터·파일럿 배치와
실제 스펙트럼 점유 대역폭은 아직 미정이며, 60 MHz 격자 폭을 실측 점유
대역폭과 동일시하지 않는다.

## 평가 지표

1차 지표는 BER(잘못 수신한 정보 비트 수 / 전송한 정보 비트 수)로 확정했다.
비교 축은 수신 `Eb/N0`로 확정했다. 파형 자체의 차이를 먼저 보기 위해
첫 비교에서는 오류 정정 부호화를 적용하지 않는다. 부호화된 경우는 나중에
네 파형에 같은 부호를 적용하는 별도 실험으로 다룬다. `Eb/N0` 예비 탐색은
위와 같이 정했다. 반복 측정은 각 지점의 공통 총 데이터 비트 수로 종료하며,
세밀 측정 구간과 신뢰구간 계산 세부 사항·보조 지표는 이후 결정한다.

## 통과 구간 다시 계산하기

Python 3.12 이상 환경에서 이 폴더를 현재 작업 위치로 두고 실행한다.

```powershell
python -m pip install -r requirements.txt
python select_pass.py
```

`select_pass.py`가 출력한 결과를 `scenario.json`의 `selected_pass`와 비교한다.
보정 전 최대 공통 도플러도 함께 계산하려면 다음 명령을 사용한다. 이 옵션의
출력에는 `selected_pass`와 `common_doppler_envelope`가 함께 포함된다.

```powershell
python select_pass.py --doppler-envelope
python select_pass.py --doppler-envelope --doppler-step-s 0.125
```

좌표 변환에는 WGS-84와 1차 TEME→ECEF 회전을 사용하고, 원본과 같이 UTC를
UT1의 근사값으로 사용하며 극운동은 생략한다.
