# 2nd session: Starlink downlink 방식 비교

OFDM, AFDM, OTFS, DD-a-OFDM 비교를 위한 공통 시나리오를 관리한다.
현재 `scenario.json`에는 위성과 지상국의 기하 조건 및 1차 평가 지표 BER을 정의했다.
Ku 다운링크, 공통 반송파 주파수 11.7 GHz, 공통 명목 격자 대역폭 60 MHz를
사용한다. 첫 다중경로 비교용 경로 수·지연·상대 전력·도플러 및 경로 위상의
시행 간 변경 방식은 정했지만, 전력 정규화·수신기 가정은 아직 결정하지 않았다.

## 채널 구성 순서

첫 비교의 기본 채널은 위성에서 지상국까지의 LOS 단일경로(LOS 포함 총 1경로)로
정했다. 위성 궤도에서 계산한 LOS 도플러를 적용하고, 수신 `Eb/N0`를 바꾸며
BER을 본다. 이는 다중경로를 무시한 통제 실험이지 실제 지상국 주변에 반사가
없다는 주장은 아니다. 이후 LOS를 포함한 다중경로 채널을 별도 비교 조건으로
추가한다. 첫 다중경로 실험은 LOS 1개와 추가 경로 2개, 총 3경로로 정했다.
이는 계산 가능한 통제 모델의 선택이지 해당 지상국에서 실제 측정된 경로
수가 아니다. 첫 다중경로 비교에 사용할 프로파일은 다음과 같다. 지연은 위성에서
지상국까지의 전체 전파시간이 아니라 LOS에 대한 **초과 지연**이다.

| 경로 | LOS 대비 초과 지연 | 60 MHz 기준 샘플 수 | LOS 대비 상대 전력 | LOS 대비 추가 도플러 |
| --- | ---: | ---: | ---: | ---: |
| LOS | 0 ns | 0 | 0 dB | 0 Hz |
| 반사 1 | 약 33.3 ns | 2 | −10 dB | 0 Hz |
| 반사 2 | 약 83.3 ns | 5 | −15 dB | 0 Hz |

두 도플러 시점에서 지연과 상대 전력은 동일하게 유지하고, 각 시점의 궤도에서
계산한 LOS 도플러를 세 경로에 공통으로 적용한다. 수신국과 주변 반사체가
고정된 상황의 첫 근사이며, 반사체의 실제 위치를 모르므로 경로별 추가
도플러를 임의로 주지 않는다. 이는 도플러 **편이**는 포함하지만 경로 간
도플러 **확산**은 포함하지 않는 모델이다. 따라서 네 파형의 이중 확산 채널
성능은 이후 별도의 합성 스트레스 실험이 필요하다. 위 지연·전력 값은 통제
실험용 선택이지 실제 Starlink–성균관대 링크의 측정치나 표준 NTN 경로
프로파일이 아니다.

첫 비교에서는 각 경로의 크기를 위 상대 전력대로 한 프레임 내내 고정한다.
반사경로의 상대 위상은 독립 BER 시행마다 새로운 무작위 조합을 사용하되,
한 시행의 프레임 안에서는 고정한다. 같은 시행의 네 파형과 저·고도플러
시점에는 동일한 초기 상대 위상 조합을 적용해 도플러 조건만 통제해서
비교한다. 프레임 안에는 궤도 기반 공통 도플러의 위상 회전만 남기고,
경로 크기의 시간 변화나 경로 간 추가 위상·도플러 변화는 넣지 않는다.
따라서 여러 정적 반사 조합을 비교하지만 시간 선택적 페이딩을 모델링하는
것은 아니다. 시간 변화 페이딩은 나중의 별도 실험으로 미룬다. 무작위
위상의 구체적인 확률분포, 총 수신 전력 정규화 방식 및 파형별
프리픽스/보호구간 길이는 아직 정하지 않았다.

## 도플러 비교 계획

네 파형을 도플러가 작은 조건과 큰 조건에서 각각 비교한다. 각 조건은 선택된
위성 통과의 한 시점을 고정해 사용하며, 두 조건 모두 네 파형에 같은 수신
`Eb/N0` 값을 적용한다. 따라서 예비 탐색에서는 네 파형 × 두 도플러 조건의
BER 곡선을 살펴본다. 고도만을 기준으로 도플러 값을 가정하지 않고,
선택할 시점의 궤도에서 도플러를 계산한다. 따라서 우리가 정할 것은 두
대표 시각의 선택 기준이며, 도플러 수치는 임의로 정하지 않는다. 현재 통과
초안에서는 최고 고도각 시점(07:46:50.803 UTC)을 저도플러 조건으로,
고도각 10°의 이탈 시점(07:51:02.674 UTC)을 고도플러 조건으로 정했다.
수신기의 도플러 보정 여부는 아직 정하지 않았다. 두 시점의 다른 채널 조건이
함께 바뀌면 결과를 도플러 효과만으로 해석할 수 없으므로, 그 통제 방식도
채널 모델을 정할 때 결정한다.

현재 시나리오 초안의 통과를 기준으로 경사거리의 1초 중앙차분과
`f_D ≈ -f_c (dR/dt)/c`를 적용하면, 고도각 10°의 진입 시점은 약 +260.9 kHz,
선택한 최고 고도각 시점은 약 +0.5 kHz, 최근접 시점은 약 0 kHz,
선택한 이탈 시점은 약 -261.0 kHz다.
이는 제공된 OMM 궤도와 지상국 좌표, 공통 대표 반송파 11.7 GHz에서
계산한 예측값이며, 실제 송신 신호를 측정한 값은 아니다. 통과 날짜·최소
고도각 자체는 아직 시나리오 초안이므로 변경하면 시각과 도플러를 다시 계산한다.

## 확정한 실험 목적

동일한 성균관대–STARLINK-5285 다운링크 조건과 동일한 수신 `Eb/N0`에서
OFDM, AFDM, OTFS, DD-a-OFDM 네 송수신 방식의 BER을 비교한다.
BER 비교 축은 수신 `Eb/N0`이며, 예비 탐색 범위와 간격은 아래에 정했다.

## 확정한 링크 방향과 대역

성균관대 지상국은 수신만 하며, 위성에서 지상국으로 오는 Ku 다운링크만
비교한다. Ku는 사용할 주파수 대역이고, 신호가 실제 차지하는 대역폭은
별도로 정한다. 네 방식의 공통 반송파 주파수는 11.7 GHz로 정했다.
이는 BER 비교를 위한 Ku 대역 대표값이며, STARLINK-5285가 해당 통과에서
실제로 사용한 채널 중심이라는 주장은 아니다. 명목 격자 대역폭은 아래와 같이
정했다. 첫 BER 비교에서는 가장자리 보호칸과 중앙 DC 빈 칸을 모두 두지 않는다.
실제 스펙트럼 점유 대역폭은 아직 정하지 않았다.

## 확정한 심볼 변조 방식

OFDM, AFDM, OTFS, DD-a-OFDM 모두 같은 16-QAM 심볼을 사용한다. 한 심볼에
4비트를 담는다. 비트-심볼 매핑과 심볼 전력 정규화 방식은 아직 정하지 않았다.
이는 네 파형 중 하나를 고른다는 뜻이 아니라, 네 파형에 넣을 심볼을 공통으로
정한 것이다.

## 수신 Eb/N0 탐색 계획

첫 BER 비교에서는 네 파형 모두에 같은 수신 `Eb/N0` 값 0, 5, 10, 15, 20,
25, 30 dB를 적용해 넓은 구간을 먼저 탐색한다. 이는 적은 측정 지점으로
BER 변화 구간을 찾기 위한 예비 범위이며, STARLINK-5285에서 측정하거나
링크 예산으로 계산한 SNR 범위가 아니다. 예비 결과에서 BER이 변하거나
파형 차이가 나타나는 구간을 골라 1~2 dB 간격으로 다시 측정한다. 정확한
세부 구간과 간격은 예비 결과를 보고 결정하고, 필요하면 시작·끝값도 확장한다.

## 대역폭 결정과 근거

네 방식의 공통 명목 격자 대역폭은 `B = N × Δf = 256 × 234.375 kHz = 60 MHz`다.
[Starlink Ku 신호 관측 연구](https://radionavlab.ae.utexas.edu/wp-content/uploads/starlink_structure.pdf)의
채널당 240 MHz와 같은 부반송파 간격을 유지하면서, BER 반복 계산의 부담을
줄이기 위해 격자 크기를 1024에서 256으로 줄였다. 이는 계산 편의를 위한
실험 설정이며 STARLINK-5285가 사용한 실제 대역폭이라는 뜻은 아니다.
명목 대역폭 기준 지연 분해능 `1/B`는 약 16.7 ns로, 240 MHz의 약 4.17 ns보다
낮다. 따라서 나중에 다중경로 채널을 정할 때 이 차이를 해석에 반영해야 한다.
첫 BER 비교의 왼쪽·오른쪽 가장자리 보호칸은 각각 0개로 정했다. 네 파형에
같은 규칙을 적용하고, 보호칸을 둔 경우는 이후 별도의 민감도 실험에서 살펴본다.
이는 계산 및 비교를 위한 단순화이며, 실제 송신 신호에 보호 대역이 없다는
주장은 아니다. 중앙 DC 칸도 비우지 않아 256개 주파수 칸을 모두 사용할 수
있다. DC를 비운 경우 역시 이후 별도로 비교한다. 데이터·파일럿 배치와
실제 스펙트럼 점유 대역폭은 아직 미정이며, 60 MHz 격자 폭을 실측 점유
대역폭과 동일시하지 않는다.

## 시나리오 초안

- 지상국: 성균관대학교 자연과학캠퍼스, 북위 37.2934°, 동경 126.9747°,
  고도 0 m(참고 저장소의 좌표 가정).
- 위성: STARLINK-5285, NORAD 55296. 2026-07-27 11:53:54.484800 UTC의
  고정 OMM 자료를 SGP4로 전파한다.
- 검색: 2026-07-29 UTC 하루, 고도각 10° 이상인 통과 중 최고 고도각이 가장
  높은 통과를 선택한다. 날짜·고도각 기준은 검토를 위한 초안이다.
- 선택된 통과: 07:42:36.760–07:51:02.674 UTC, 최고 고도각 85.164878°
  (07:46:50.803 UTC). 최근접 시각은 07:46:50.954 UTC다.

자료 출처는 [`cmj0731/starlink-downlink-simulation`의 `955f0818` 커밋](https://github.com/cmj0731/starlink-downlink-simulation/tree/955f0818f66104cb8d264bbcccf39c117319b26c)이다.
지상국 좌표와 궤도 자료만 고정 입력으로 가져왔으며, 원본의 파형·주파수·채널
설정은 이번 비교에 채택하지 않았다.

## 평가 지표

1차 지표는 BER(잘못 수신한 정보 비트 수 / 전송한 정보 비트 수)로 확정했다.
비교 축은 수신 `Eb/N0`로 확정했다. 파형 자체의 차이를 먼저 보기 위해
첫 비교에서는 오류 정정 부호화를 적용하지 않는다. 부호화된 경우는 나중에
네 파형에 같은 부호를 적용하는 별도 실험으로 다룬다. `Eb/N0` 예비 탐색은
위와 같이 정했으며, 세밀 측정 구간, 반복 횟수와 보조 지표는 이후 결정한다.

## 통과 구간 다시 계산하기

Python 3.12 이상 환경에서 이 폴더를 현재 작업 위치로 두고 실행한다.

```powershell
python -m pip install -r requirements.txt
python select_pass.py
```

`select_pass.py`가 출력한 결과를 `scenario.json`의 `selected_pass`와 비교한다.
좌표 변환에는 WGS-84와 1차 TEME→ECEF 회전을 사용하고, 원본과 같이 UTC를
UT1의 근사값으로 사용하며 극운동은 생략한다.
